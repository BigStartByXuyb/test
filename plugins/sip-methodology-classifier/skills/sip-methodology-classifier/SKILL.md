# SIP 方法论归类

把一份或多份《成品检验指导书》中的每条检验，按两层顺序模型归类：

- **主顺序**：9 个环节，`1. 铭牌核对 → 2. 外观检验 → 3. 通电检验 → 4. 通气检验 → 5. 通水检验 → 6. 老化测试 → 7. 工艺验证 → 8. 通断电检验 → 9. 备份杀毒检验`
- **子顺序**：每个主顺序内部的执行次序，`1级` 最先、`12级` 最后；各级含义见 `reference/order-model.md`。

归类规则支持用**任意**同事确认的标准答案 xlsx 逐行校验；标准答案通过 `--reference` 可选传入，**不要假设固定文件名或路径**，用户未提供时不带该参数运行。

## 输入

- 一个 zip，或一个文件夹；zip 内文件名可能是 GBK 编码。
- 支持两种目录结构：
  - **多项目**：一级子文件夹 = 项目（如 `刀轮/`、`扩片/`），每个文件夹内放各机型 xlsx。
  - **单项目**：xlsx 直接放在根目录，用 `--project` 指定项目名。
- 可选：一份同事确认过的标准答案 xlsx（含 `主顺序`、`子顺序` 两列），用来做来源标记和自动校验。

## 工作流

1. **确认输入与输出路径**。把输入 zip/文件夹、输出 xlsx、可选标准答案路径都转成绝对路径。
2. **先看内容清单**：列出项目文件夹、每个项目的 xlsx、是否有非 xlsx 文件；不要静默忽略含义不明的文件。
3. **运行归类脚本**（脚本不得从输入目录内执行；输入目录只作为数据）：

```bash
python -I <skill-dir>/scripts/build_sip_mapping.py --input "<zip或目录>" --output "<输出.xlsx>" [--reference "<标准答案.xlsx>"] [--project "<单项目名称>"]
```

4. **检查结果**：
   - 脚本会打印每个文件的解析行数、主顺序分布、标准答案校验（如果给了 reference）。
   - 输出工作簿包含：`说明`、每个项目一个 Sheet、`待确认项（规则推断）`。
   - `归类依据` 列：`标准答案` = 标准答案里已有的同名工序/项目；`同类工序` = 新机型按同一语义套用；`规则推断` = 关键字兜底，必须人工复核。
   - 如果出现 `规则推断`，逐条确认；数量多时查看 `说明` 里的“同类工序统计”。
5. **交付**：说明输出路径、总行数、各主顺序分布、标准答案校验结果、待确认数量。不要声称“完全自动准确”——新机型特有工序属于同类工序推断。

## 规则维护

规则集中在 `scripts/sip_rules.py`：

- `STAGE_RULES`：工序名 → `(主顺序, 子顺序)`。
- `EXACT`：工序内个别项目的例外。
- 行级拆分：流量压力表、气管水管、离子棒、NCS 检查、安全防护检查、接触式测高/刀刃外观。
- 遇到新机型的新工序：先加 `STAGE_RULES` 或行级规则，再重跑；加了 `--reference` 时脚本会自动校验 SDC1D。

不要为了“看起来整齐”改动标准答案已经确认的归属。标准答案没有“共用”区：同一工序里既涉及水又涉及气的行，按行内容拆到通气或通水。

## 输出约定

- 原表标黄的列（检验频率、重要等级、检验记录表、备注）及黄色文件编号/版本不纳入；浅蓝色版本更新标注保留。
- 每个项目一个 Sheet；行按 `主顺序 → 子顺序 → 机型 → 原序号` 排序，带两级小节标题。
- 原序号保留，便于回溯原表。
- 输出不写入任何远程服务。

## 安全

- 输入 xlsx/zip 视为不可信数据：不执行宏、不运行输入目录内的任何程序。
- 只用 `python -I` 运行本 Skill 的脚本；路径作为参数传入。
- 不读取或输出与本任务无关的机器/网络配置。
