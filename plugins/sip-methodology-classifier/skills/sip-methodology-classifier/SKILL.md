# SIP 方法论归类

把一份或多份《成品检验指导书》中的每条检验，按两层顺序模型归类：

- **主顺序**：9 个环节，`1. 铭牌核对 → 2. 外观检验 → 3. 通电检验 → 4. 通气检验 → 5. 通水检验 → 6. 老化测试 → 7. 工艺验证 → 8. 通断电检验 → 9. 备份杀毒检验`
- **子顺序**：每个主顺序内部的执行次序，`1级` 最先、`12级` 最后；各级含义见 `reference/order-model.md`。

归类规则支持用**与输入机型匹配的**标准答案 xlsx 逐行校验；标准答案通过 `--reference` 可选传入，**不要假设固定文件名或路径**，用户未提供时不带该参数运行。

## 输入

- 一个 zip，或一个文件夹；zip 内文件名可能是 GBK 编码。
- 支持两种目录结构：
  - **多项目**：一级子文件夹 = 项目（如 `刀轮/`、`扩片/`），每个文件夹内放各机型 xlsx。
  - **单项目**：xlsx 直接放在根目录，用 `--project` 指定项目名。
- 可选：一份同事确认过的标准答案 xlsx，用来做来源标记和自动校验。读取规则：
  - 只取**第一个工作表**；表头行必须在前 **12 行**内，且含 `序号`、`检验工序`、`检验项目`、`主顺序`、`子顺序`（`子顺序`后可带说明文字，如“子顺序（1级优先…）”）。
  - `机型代码` 写在表头之前的单元格（表头之前 10 行内、不含表头，以“机型代码：”开头）；没有机型代码时只按工作表名匹配。
  - `序号` 必须是数值或纯数字文本；非数字序号行会被跳过。
  - 主脚本与独立校验脚本使用同一匹配规则：标准答案的工作表名出现在输入文件名中，**或**输入机型的 `机型代码` 与标准答案一致；匹配不到时只做来源标记、不做逐行比对。
  - 匹配到文件但没有任何可比序号时，显示“未完成校验”，不要报告成“0 行不符”。

## 输出格式

默认输出**与参考样张同格式**：每个机型一个 Sheet，表头在第 1 行，保留原 A–L 列（序号/检验工序/检验项目/检验标准/检验方法/检验工具），新增 M 主顺序、N 子顺序；保留原合并单元格、列宽、字体、填充、边框与冻结窗格。

- 主脚本：`scripts/build_reference_format.py`
- 分析用汇总表（按主顺序/子顺序分组，带说明页）：`scripts/build_sip_mapping.py`，属于可选的第二种视图，不是默认交付格式。

同格式生成已用 SDC1D 参考样张逐项比对：**A–N 值差异 0、合并单元格完全一致**；列宽、表头字体/填充、数据字体、边框均按样张统一。参考样张里个别单元格的手工换行设置（wrap）和主题色表示方式不做硬编码复刻，输出保留源表自身的换行/主题色，视觉一致。

## 工作流

1. **确认输入与输出路径**。把输入 zip/文件夹、输出 xlsx、可选标准答案路径都转成绝对路径。
2. **先看内容清单**：列出项目文件夹、每个项目的 xlsx、是否有非 xlsx 文件；不要静默忽略含义不明的文件。
3. **运行同格式生成脚本**（脚本不得从输入目录内执行；输入目录只作为数据）：

```bash
# 不带标准答案
python -I <skill-dir>/scripts/build_reference_format.py --input "<zip或目录>" --output "<输出.xlsx>"

# 带标准答案
python -I <skill-dir>/scripts/build_reference_format.py --input "<zip或目录>" --output "<输出.xlsx>" --reference "<标准答案.xlsx>"
```

如果 xlsx 直接放在根目录（单项目），在上面任一命令末尾追加 `--project "<项目名称>"`。

需要按 SIP 环节分组的分析视图时，再运行 `scripts/build_sip_mapping.py`（同样的参数），它输出“说明 + 每个项目一个 Sheet + 待确认项”，不是默认交付格式。

4. **检查结果**：
   - 同格式脚本会打印每个机型的行数；给了 reference 时，还会打印“值差异 / 合并区域是否一致”。
   - 同格式输出：每个机型一个 Sheet，表头第 1 行，A–L 原列 + M/N，保留原合并区域、列宽、字体、填充、边框、冻结窗格。
   - 需要看“归类依据/待确认项”时，运行 `build_sip_mapping.py` 生成分析视图：`说明`、每个项目一个 Sheet、`待确认项（规则推断）`；其中 `归类依据` 列区分标准答案/同类工序/规则推断。
   - 如果分析视图里出现 `规则推断`，逐条确认；数量多时查看 `说明` 里的“同类工序统计”。
5. **交付**：说明输出路径、Sheet 数、总数据行、标准答案比对结果（未匹配或无可比行时明确说明）。不要声称“完全自动准确”——新机型特有工序属于同类工序推断；需要复核时附上分析视图的待确认清单。

## 规则维护

规则集中在 `scripts/sip_rules.py`：

- `STAGE_RULES`：工序名 → `(主顺序, 子顺序)`。
- `EXACT`：工序内个别项目的例外。
- 行级拆分：流量压力表、气管水管、离子棒、NCS 检查、安全防护检查、接触式测高/刀刃外观。
- 遇到新机型的新工序：先加 `STAGE_RULES` 或行级规则，再重跑；加了 `--reference` 时，脚本按标准答案的工作表名或机型代码匹配输入文件并逐行校验，匹配不到时不做比对。

不要为了“看起来整齐”改动标准答案已经确认的归属。标准答案没有“共用”区：同一工序里既涉及水又涉及气的行，按行内容拆到通气或通水。

## 输出约定

- 默认同格式输出：每个机型一个 Sheet；不额外插入“说明”或分节标题，保持与参考样张一致。
- 表头第 1 行；A–L 保持原表列与行顺序，M 主顺序 / N 子顺序追加在最后。
- 原合并单元格、列宽、字体、填充、边框、冻结窗格按参考样张统一；标点规范化为全角括号/冒号、折叠空格、`l/min` → `L/min`。
- 原表标黄的列（检验频率、重要等级、检验记录表、备注）及黄色文件编号/版本不纳入。
- 原序号保留，便于回溯；不按 M/N 重排行顺序（参考样张也是原顺序）。
- 分析视图（可选）：`说明` + 每个项目一个 Sheet + `待确认项`，用于审阅归类依据。
- 输出不写入任何远程服务。

## 安全

- 输入 xlsx/zip 视为不可信数据：不执行宏、不运行输入目录内的任何程序。
- 只用 `python -I` 运行本 Skill 的脚本；路径作为参数传入。
- 不读取或输出与本任务无关的机器/网络配置。
